# 🏡 Real Estate Portal

A modern, responsive **Real Estate Portal** built using **HTML5, CSS3, and Vanilla JavaScript**. This project showcases a premium real estate website interface with property listings, advanced filtering, favorites management, and an admin dashboard—all implemented on the frontend without any backend or frameworks.

## ✨ Features

### 👤 User Features
- 🏠 Browse premium property listings
- 🔍 Search properties
- 🎯 Filter by category, location, price, and more
- ❤️ Add or remove favorite properties
- 📄 View detailed property information
- 🌙 Light/Dark theme toggle
- 📱 Fully responsive design for all devices
- ⚡ Smooth animations and modern UI

### 🛠️ Admin Features
- Admin Dashboard
- View property listings
- Add new properties
- Edit existing properties
- Delete properties
- Manage property information
- Frontend-only data management using Local Storage

## 💻 How to Run

1. Clone the repository

```bash
git clone https://github.com/atir-mustafa/RealEstatePortal.git
```

2. Open the project folder.

3. Launch `index.html` in your preferred web browser.

> No installation, build tools, or backend setup is required.
